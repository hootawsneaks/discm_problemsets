# P1 - Threaded Prime Number Search
## How to run any of the four variations:
Using GNU Compiler (g++):
``` bash
g++ -pthread -std=c++20 main.cpp -o main
./main
```
Using Mac/libc/clang++:
``` bash
clang++ -pthread -fexperimental-library -std=c++20 main.cpp -o main
./main
```

Thread and range are adjustable via the config file provided.
